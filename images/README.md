# Image assets

Replace Unsplash URLs in `src/data/*` with files placed here.

Suggested structure:

- `logo/` — brand mark & wordmark
- `hero/` — homepage hero stills or video poster
- `projects/project-1/` … `project-5/` — hero, gallery, master plan
- `locations/` — market cards
- `blog/` — article covers
- `testimonials/` — optional avatars

Keep originals under ~200KB where possible (WebP/AVIF preferred).
